# Virtuoso v0.1.0

Virtuoso v0.1.0 is the first source release candidate prepared for maintainer review. It provides the local Python CLI. The Hermes and Obsidian plugins remain optional.

The release includes local active recall with FSRS proposals, source-backed reviewed import, project-transfer evidence, read-only analytics, and local lexical or caller-supplied-vector retrieval. The CLI owns learning state and remains usable without either plugin.

The release workflow builds the Python wheel and source distribution. It also builds the Obsidian plugin files. It verifies every asset before it creates a draft GitHub Release. A maintainer must review and publish that draft. This workflow does not publish to PyPI or deploy a service.

See the [CLI reference](../12-cli-reference.md) for current commands and the [documentation index](../README.md) for design and verification records.
